# Reportar uma falha de segurança

Não publique dados de conta, conversas, tokens ou uma exploração com dados pessoais numa issue. Use o recurso **Report a vulnerability** do repositório quando estiver habilitado. Se ele estiver indisponível, abra uma issue apenas pedindo um canal privado, sem os detalhes da falha.

A extensão só deve operar nas origens declaradas no manifesto, não enviar mensagens automaticamente e não coletar conversas. O site não recebe dados de pagamento; pagamentos, quando configurados, acontecem no GitHub Sponsors.
