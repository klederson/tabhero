# Report a security issue

Please do not publish account data, conversations, tokens, or an exploit containing personal information in an issue. Use the repository’s **Report a vulnerability** feature when available. If it is unavailable, open an issue asking only for a private reporting channel, without disclosing the vulnerability details.

TabThere should operate only on origins declared in its manifest, never send messages automatically, and never collect conversations. Integration failures must leave the existing WhatsApp document intact, with no navigation or reload fallback. Browser tests simulate WhatsApp interfaces and do not establish security or compatibility in an authenticated real session.

The website does not collect payment details. Optional payments, once enabled, take place on GitHub Sponsors. Receiving payments is currently pending; no charge is made by the website.
