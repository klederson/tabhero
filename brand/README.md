# TabHero — brand kit

New chat. Same tab.

The symbol is a browser tab with an arrow returning inside it. It does not use a speech bubble or phone. The displayed wordmark is **tabhero.**; write **TabHero** in running text. SVG lettering is converted to outlines so the form does not depend on installed fonts.

The kit contains `logo.svg`, `logo-mono.svg`, `logo-on-dark.svg`, `symbol.svg`, `symbol-mono.svg`, `icon-512.png`, `social-card.png`, `brand-book.pdf`, and `tokens.json`. The social artwork source is included; local fonts are in `website/assets/fonts/` in the repository. The downloadable archive is `tabhero-brand-kit.zip`.

[The brand guide](https://klederson.github.io/tabhero/brand-book.html) covers color, typography, clear space, and voice. Its PDF title is **TabHero Brand Guide**. Do not combine the identity with the WhatsApp logo. Describe compatibility with WhatsApp Web without implying a partnership. An original identity reduces confusion; it does not establish trademark availability or legal clearance.

TabHero 1.4.0 is experimental. Tests simulate WhatsApp interfaces; integration with a real signed-in session has not been validated in this development session. A simulated demonstration must be labeled as such.

The best version of TabHero? The one you never have to install. That is a hope for native adoption, not an acquisition request. The MIT license permits reuse under its terms; nobody is obliged to adopt or acquire the project.
